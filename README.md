ConvoCloud
==========


![Example of ConvoCloud](https://i.imgur.com/0fP2LqW.png "Example of ConvoCloud")


### Description

Convo Cloud is an application to create colorful text based images with words taken from conversations with your friends or selected files on your mobile device. <br>
This application is still in beta and as such some features may not work as intended. Many improvements are in progress.<br>
If you have any privacy concerns or inquiries, please send me an email and I will respond as soon as possible.
Thank you.
